开启云原生 Hexo 博客之旅｜个人建站记录

小橙崽2026-09-162026-09-18

折腾许久，终于搭建好了属于自己的 Hexo 个人博客。全程基于云原生环境搭建，依托 AI 辅助优化配置、调试主题，省去了本地繁琐的环境部署，真正实现了云端写作、云端维护、自动部署的极简博客工作流。

从此，写作不再受设备限制，随时随地都能记录生活、沉淀知识、分享心得。

🌤 为什么选择 Hexo + 云原生？

之前也了解过很多博客搭建方案，有的配置复杂、有的加载缓慢、有的需要本地环境常驻，对新手极其不友好。最终选择 Hexo，核心原因只有三个：轻量、简洁、高效。

搭配云原生开发环境后，优势被无限放大：

  • 无需本地部署环境：不用在电脑安装 Node、Git、Hexo，全程云端操作
  • AI 辅助快速搭建：主题配置、代码调试、部署脚本全部智能优化
  • 源码云端备份：所有博客源码自动同步 GitHub，不怕丢失、不怕换设备
  • 全自动部署更新：写完文章推送源码，网站自动编译、自动更新

⚙️ 我的博客工作流（极简全自动）

经过多次调试，最终定型一套零负担写作流程，也是我未来长期使用的方式：

云原生写文章 / 改配置 → Git 提交源码 → GitHub Actions 自动编译 → 自动更新博客网站

全程不需要手动编译、不需要本地部署、不需要折腾静态文件。

推送完成后，GitHub 会自动构建、自动部署，几十秒后全网即可访问最新内容。

📝 未来写作规划

搭建博客的初衷，不是跟风折腾，而是想给自己一个沉淀输出的窗口。

未来会在这里持续更新：

  • 日常随笔、生活感悟
  • 技术学习记录、踩坑总结
  • 优质文案、读书笔记、成长碎片
  • 所见、所闻、所思、所想

文字是最好的存档，时间会见证成长。

✨ 写在最后

从 0 到 1 搭建完整个博客，最大的感受是：技术的意义，是让记录变得更简单，让输出变得更自由。

往后，在这里认真记录、持续输出，慢慢打磨属于自己的一方小天地。

前路漫漫，亦灿灿，保持热爱，持续奔赴。
